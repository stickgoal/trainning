## 极简版 HumanInTheLoop（教学用，新增独立模块）
- 需求：用最简单易懂的方式实现 HITL，方便讲解「挂起→人工→恢复」原理。
- 思路：不动原有的官方 `@HumanInTheLoop`（线程阻塞 + PendingResponse + MyBatis 持久化 + 序列化恢复）复杂实现，
  而是新增一套**框架无关、无 DB、无 LLM** 的极简版，把机制「显形」。
- 新增包 `com.example.agentic.hitlsimple`：
  - `model/PendingRequest.java`：挂起状态载体（= 官方版 PendingResponse + AgenticScope 的可见化）。
  - `model/SimpleHitlResponse.java`：统一返回体 + 静态工厂。
  - `service/SimpleHitlService.java`：核心。内存 `ConcurrentHashMap` 存挂起状态；submit 跑「审批前」步骤→挂起返回 requestId；
    approve 凭 requestId 找回→注入决策→跑「审批后」步骤→返回结果。含 status/listPending。
  - `controller/SimpleHitlController.java`：`/api/hitls/{submit,approve,status,pending}`。
- 教学页 `src/main/resources/static/hitl-simple.html`：三要素讲解 + 两段式可视化流程 + 提交/审批/查状态/待审批列表，
  带复制 curl、请求/响应 JSON 展示。
- 三核心要素（讲解主线）：①挂起状态 ②关联令牌 requestId ③人工决策通道（独立 /approve 接口）。
  强调 Web 场景 submit 立即返回、不阻塞线程，与官方版「单调用内线程阻塞」的区别。
- 「审批前/审批后」用确定性规则代替 LLM，注释说明真实项目此处换 LLM Agent 即可。
