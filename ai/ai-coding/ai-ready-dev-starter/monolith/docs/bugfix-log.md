# Bug 修复记录

> 本文件记录所有已修复的 bug，目标是**同类 bug 不再发生**。修复 bug 前先查本文件，修复后必须登记。

## 登记规则

1. 每修一个 bug，登记一条记录，含**现象 / 根因 / 修复 / 预防**四要素。
2. 若根因属"本应早知道"的模式问题，必须回写到 `docs/skills/` 对应技能的 Common Mistakes。
3. 修复前先检索本文件与 skills 的 Common Mistakes，避免重复踩坑。
4. 在 `CHANGELOG.md` 记一行摘要，链接到本文件对应条目。

## 记录模板

```markdown
### BUG-NNN：<!-- 一句话标题 -->

| 项 | 内容 |
|----|------|
| 日期 | YYYY-MM-DD |
| 现象 | <!-- 用户/测试/日志看到什么 --> |
| 根因 | <!-- 为什么发生 --> |
| 修复 | <!-- 怎么改的，涉及哪些文件 --> |
| 预防 | <!-- 如何避免再犯：新增规则/测试用例/回写的 skill --> |
| 关联 | <!-- 任务卡 / PR / 测试用例编号 --> |
```
