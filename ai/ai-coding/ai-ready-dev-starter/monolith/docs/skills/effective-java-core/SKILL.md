# Effective Java 核心技能

## When To Use

编写或评审 Java 代码时（对象创建/生命周期、equals/hashCode、类与接口设计、泛型、枚举/注解、方法设计、通用编程、异常、序列化）。并发专项见 `effective-java-concurrency`。

## Rules（按条目分组）

### 创建和销毁对象（1-7）
- 静态工厂优于构造器（有命名、实例控制、可返回子类型时）。
- 参数多时用 Builder，不用重叠构造器。
- 单例用 `enum`（或私有构造 + 静态字段）。
- 工具类私有构造禁止实例化。
- 避免创建不必要对象（复用不可变对象、缓存昂贵对象、避免装箱）。
- 消除过期引用（缓存/监听器/ThreadLocal 及时清理）。
- 不用 finalizer，用 `AutoCloseable` + try-with-resources。

### 所有对象通用的方法（8-12）
- `equals` 满足自反/对称/传递/一致/非空。
- 重写 `equals` 必重写 `hashCode`。
- 值类型重写 `toString`，包含关键状态。
- 避免 `clone`，用拷贝构造/工厂。
- 有自然顺序时实现 `Comparable`，比较避免用减法。

### 类和接口（13-22）
- 最小化可访问性；公开类用访问器，不暴露可变字段。
- 最小化可变性，字段尽量 `final`，防止表示泄露。
- 组合优先于继承；继承只用于真「is-a」。
- 为继承设计并文档化，否则禁止（`final`）。
- 接口优于抽象类；不用常量接口。
- 类层次优于标签类；静态成员类优于非静态。

### 泛型（23-29）
- 不用原始类型；消除未检查告警，`@SuppressWarnings` 局部且有理由。
- 列表优先于数组；优先泛型类型/方法。
- 有界通配符 PECS（生产者 `extends`、消费者 `super`）。

### 枚举和注解（30-37）
- 用枚举不用 `int` 常量；不用 `ordinal()`（用实例字段）。
- 用 `EnumSet`/`EnumMap` 不用位域/序数索引。
- 注解优先于命名模式；`@Override` 一致使用。

### 方法（38-44）
- 校验参数，快速失败；必要时防御性拷贝。
- 方法签名清晰（避免长参数列表，优先枚举）。
- 重载谨慎，可能混淆时用不同方法名。
- 返回空数组/集合，不返回 null。
- 暴露 API 写文档注释，说明契约与边界。

### 通用编程（45-56）
- 局部变量作用域最小化；优先 for-each。
- 精确值用 `BigDecimal`/`int`/`long`，不用 `float`/`double`。
- 优先基本类型；ID/金额用恰当类型，不用字符串。
- 循环拼接用 `StringBuilder`；通过接口引用对象。
- 优化要测量，不提前微优化。

### 异常（57-65）
- 异常只用于异常条件；可恢复用受检异常，编程错误用运行时异常。
- 优先标准异常；异常抽象到恰当层次，不泄露底层细节。
- 失败保持原子性；绝不忽略异常。

### 序列化（74-78）
- `Serializable` 谨慎实现（成为导出 API 的一部分）。
- 自定义序列化形式，声明 `serialVersionUID`；防御性 `readObject`。
- 复杂不变量优先序列化代理。

## Common Mistakes

- **重写 equals 不重写 hashCode**：放进 Set/Map 出 bug。
- **用 `float`/`double` 存金额**：精度丢失。用 `BigDecimal` 或分（int/long）。
- **返回 null 集合**：调用方要判空。返回空集合。
- **用 `ordinal()`**：顺序一变全乱。用实例字段。
- **异常当控制流**：性能差且可读性差。
- **不校验参数**：错误延后爆发难定位。快速失败。
