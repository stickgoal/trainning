# 变更记录（CHANGELOG）

本文件记录项目的迭代里程碑与 bug 修复摘要。它是 `versions/` 的替代，统一以时间倒序维护。

> bug 的详细记录（现象/根因/修复/预防）见 `docs/bugfix-log.md`，本文件只记摘要与里程碑。

## 维护规则

- 新增功能、重构、架构调整、依赖升级等，在对应版本小节下追加一条。
- 修复 bug：在「bug 修复」小节记一行摘要，详细登记到 `docs/bugfix-log.md`。
- 版本号遵循语义化版本（`主.次.修订`），关键节点打 Git tag。
