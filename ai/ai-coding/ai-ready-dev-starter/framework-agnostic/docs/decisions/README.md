# 架构决策记录（ADR）

本目录记录关键架构决策。每条决策用独立 `ADR-NNN-标题.md` 文件。

> 质疑或更改某个设计选择前，先查阅对应 ADR 确认背景；推翻旧决策应新建 ADR 而非直接改旧的。
