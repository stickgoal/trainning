## 4. 设计原则

- **分层单向依赖**：路由 → 业务 → 数据，禁止反向或跨层。
- **薄 Controller**：API 层只做校验与包装，业务规则下沉 Service。
- **统一返回与异常**：统一响应结构，业务异常由全局处理器翻译。
- **事务内聚**：跨多表写放在同一本地事务，条件更新防并发。
