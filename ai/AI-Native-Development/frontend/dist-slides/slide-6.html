00_setup.py
Python · OpenAI 兼容 
 1  from openai import OpenAI
 2
 3  client = OpenAI(
 4      api_key=os.getenv("DEEPSEEK_API_KEY"),
 5      base_url="https://api.deepseek.com",
 6  )
 7
 8  response = client.chat.completions.create(
 9      model="deepseek-chat",
10      messages=[{"role": "user", "content": "你好"}],
11  )
12  print(response.choices[0].message.content)
这是整个生态的 Hello World

相当于 Spring Boot 的启动类——先确认环境、跑通最简调用。

Python 语法要点（Java 类比）
  • from X import Y → import
  • f"..." → String.format
  • chat.completions → 链式属性

💡 换通义千问 / 智谱：只改 base_url 即可，代码不变。
