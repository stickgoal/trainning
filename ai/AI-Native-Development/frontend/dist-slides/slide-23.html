第 7 章 · 阶段 C MCP（Model Context Protocol）

MCP：N×M → N+M 的适配地狱

MCP 出现前

每个 Agent 自己接工具，N 个 Agent × M 个系统 = N×M 份适配代码。

用 MCP 后

标准化 "LLM ↔ 工具" 协议，N 个 Agent + M 个系统 = N+M 份实现。

三件套 · 类比 gRPC
Server

暴露工具的服务端（stdio / SSE / WebSocket）

Client

发现并调用工具的客户端（通常是 Agent）

Tool

被暴露的具体能力（docstring 自动转 description）

与 LangChain Tool 的区别

MCP 是跨进程 / 跨语言 / 可复用的标准协议——一个 Server 可被多个 Agent 共享。
