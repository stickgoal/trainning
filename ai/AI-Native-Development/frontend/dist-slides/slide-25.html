装饰器即注册

@mcp.tool() 把普通函数变成 Agent 可调工具（Java 注解 @RpcMethod）。

docstring 工程

函数 docstring 自动转 Tool 描述、类型提示自动转 JSON Schema。

async / await

异步调用，类比 WebFlux 的响应式，第 8 章详解。

💡 一个 Agent 接公司 N 个内部系统，不必每个手写适配。
