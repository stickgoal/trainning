第 2 章 · 阶段 A LLM Application 开发基础

8 个核心术语 · 一页讲完

Prompt
给 LLM 的输入文本
Token
文本处理单元，非字符非单词
Context
单次请求的有效上下文窗口
Embedding
文本转向量，语义可计算
Retrieval
从知识库召回相关片段
Tool Calling
LLM 决定调用哪个函数
Memory
跨轮对话状态（历史消息）
Agent
LLM + 工具 + 决策循环
Agent 的内核 · Tool Calling 四步闭环
STEP 1
发工具 Schema 给 LLM
→
STEP 2
LLM 返回 tool_call
→
STEP 3
应用层真正执行
→
STEP 4
回灌结果生成回答

关键：LLM 不执行工具，它只"决定"调用——执行权在应用层。
