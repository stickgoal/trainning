课程定位

这门课是什么 / 不是什么

目标听众
  • · 3 年以上 Java 后端经验
  • · 能读 Python，不熟 asyncio / decorator
  • · 用过 ChatGPT，没搭过 LLM 应用
  • · 不需要机器学习 / 数学背景
这门课不是
  • ✕ 不是 Python 语法课
  • ✕ 不是机器学习原理课
  • ✕ 不训练模型，不碰梯度下降
  • ✕ 不设固定时长，按需跳读
这门课是
  • ✓ 生态认知教程：建立技术地图
  • ✓ 看懂组件边界与数据流
  • ✓ 知道何时用 / 何时别用
  • ✓ 学完能画出企业级架构图
💡

对 Java 工程师的关键提示：把 LLM 当作"通过 HTTP 调用的、会推理的外部服务"， 把 Agent 当作"用 LLM 做决策、会调用工具的 Spring Service"。 剩下的问题只是"用什么框架把这两件事拼起来"。
