第 4 章 · 阶段 B · 重点 LangGraph

LangGraph：为什么 Chain 不够

Chain 的局限

Chain 是单向流水线；Agent 需要循环 + 条件 + 状态。

LangGraph 的答案

显式状态机 + 图，把 Agent 流程画成可执行的有向图。

💡 一句话：把 Agent 从"黑盒循环"变成"可中断、可观察的流程"。

4 个原语 · Java 类比
Graph
工作流骨架（有向图）
类比 BPMN 流程定义
Node
节点 = 一个函数 (state) → 更新
类比一个 Service 方法
Edge
边 = 跳转（含条件边）
类比状态机的 transition guard
State
节点间共享状态（显式化）
类比流程变量（reducer 控制合并）
