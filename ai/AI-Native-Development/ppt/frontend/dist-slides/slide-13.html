02_langchain_demo.py
LCEL 
 1  from langchain_deepseek import ChatDeepSeek
 2  from langchain_core.prompts import ChatPromptTemplate
 3  from langchain_core.output_parsers import StrOutputParser
 4
 5  prompt = ChatPromptTemplate.from_template("用一句话解释 {concept}。")
 6  model = ChatDeepSeek(model="deepseek-chat")
 7
 8  # ★ LCEL：用 | 把 prompt → model → parser 串成一条链
 9  chain = prompt | model | StrOutputParser()
10
11  # 数据流：{concept} → 填模板 → 发 LLM → 解析成纯字符串
12  result = chain.invoke({"concept": "RAG"})
13  print(result)
| 是什么？

Python 的 | 被 LangChain 重载为 Runnable 串联（运算符重载）。

统一入口

所有组件共享 invoke / ainvoke / batch / stream 四种调用方式。

换模型只改一处

OpenAI / Anthropic / 通义 / DeepSeek 都实现同一抽象。

💡 80% 的"LLM + 提示词 + 检索"场景，默认起点就是 LangChain。
