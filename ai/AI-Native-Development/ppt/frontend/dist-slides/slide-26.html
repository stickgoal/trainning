第 8 章 · 阶段 C A2A（Agent To Agent）

A2A：多 Agent 怎么协作

为什么单 Agent 不够
· 任务太复杂，单点难解
· 角色太多，职责难合一
· 上下文太长，超出窗口
要解决的三大问题
Communication
通信

Agent 之间怎么可靠地收发消息。

Discovery
发现

怎么找到"谁能干什么"，动态注册能力。

Task Delegation
任务委派

任务怎么拆分、派给谁、如何汇总。

典型流程：Research → Coding → Testing 各司其职 ｜ 一句话：多 Agent 是"微服务化"在 Agent 层的重演，3-4 个为宜，别为了拆而拆。
