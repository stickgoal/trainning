第 3 章 · 阶段 B LangChain

LangChain：把胶水代码组件化

不用 LangChain

每个项目重写 Prompt / 检索 / 记忆的胶水代码，不可复用、难以维护。

用 LangChain

把组件标准化、可复用、可组合，像搭积木一样拼 LLM 应用。

9 大组件 · 按职责分类
Chat Model
统一 LLM 调用接口
Prompt Template
变量插值复用提示词
Runnable / Chain
统一抽象与流水线
Retriever
检索器接口
Vector Store
向量存储
Memory
跨轮对话状态
Tool
函数 → 工具
Agent
LLM + Tool 决策循环
Output Parser
结构化输出
LCEL 精髓

所有组件都是 Runnable，用 | 串联成流水线 —— 类比 Java Stream.map().filter().collect()
