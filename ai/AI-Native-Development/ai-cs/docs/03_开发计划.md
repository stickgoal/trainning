## 0. 总览

| 里程碑 | 内容 | 依赖 | 需 API Key |
|---|---|---|---|
| M0 | 环境与骨架 | 无 | 否 |
| M1 | 知识语料与模拟数据 | M0 | 否 |
| M2 | RAG 基础管线（可离线验证） | M1 | 否（建库）；是（问答） |
| M3 | 多路召回 + Rerank | M2 | 否 |
| M4 | 工具 + Agent 组装 | M2 | 是 |
| M5 | FastAPI 服务 + Web 页 | M4 | 是 |
| M6 | 测试集 + 评估 + 回归 | M4 | 部分 |
| M7（可选）| MCP Server 独立进程形态 | M4 | 是 |

依赖关系：

```
M0 → M1 → M2 → M3（可与 M4 并行）
              └→ M4 → M5
                 └→ M6
                 └→ M7（可选）
```

**推荐执行顺序**：M0 → M1 → M2 → M4 → M3 → M6 → M5 → M7。
理由：M4 打通端到端主链路（Agent + 基础检索）后即可跑 S1~S5 场景验证，尽早暴露工具选择问题；M3 是质量增强，晚做不影响主流程跑通。

## M0 · 环境与项目骨架

**任务**

- [ ] T0.1 确认课程根目录 venv 可用：`.venv` 存在且已装 `requirements.txt`（若否，按课程 README 第七节初始化）；
- [ ] T0.2 验证环境：`python examples/00_setup.py` 通过（或至少验证 `langchain`、`chromadb`、`sentence-transformers` 可 import）；
- [ ] T0.3 设置环境变量：`DEEPSEEK_API_KEY`、`HF_ENDPOINT=https://hf-mirror.com`；
- [ ] T0.4 预下载模型（一次性）：`BAAI/bge-small-zh-v1.5`、`BAAI/bge-reranker-base`；
- [ ] T0.5 创建 `src/` 空包结构（含全部 `__init__.py`）+ `core/config.py` + `core/logging.py`；
- [ ] T0.6 写 `ai-cs/requirements.txt`（引用课程根 requirements 或最小子集）。

**交付物**：目录骨架、config、logging、requirements.txt。

**验收标准**

```bash
python -c "from src.core.config import Config; print(Config.KNOWLEDGE_DIR)"   # 输出路径
python -c "import langchain, chromadb, sentence_transformers; print('ok')"
```

## M1 · 知识语料与模拟数据

**任务**

- [ ] T1.1 编写 6 份制度文档（`knowledge_docs/{hr,finance,admin}/*.txt`），要求：
  - UTF-8，结构化分节（`【章节名】`），每节 3~8 条规则；
  - 必含数字型条款（天数/金额/时限/档位），供测试集出题；
  - 覆盖域：请假（年假档位/病假证明/事假上限/婚产假/审批分级）、差旅（交通舱位/住宿分线城市/餐补）、日常报销（时限/审批权限分档）、员工手册（考勤/工位/设备）、IT 支持（VPN/账号权限流程）；
  - **刻意留白**：不要写食堂/班车等内容（留给 S4 防幻觉用例验证）；
- [ ] T1.2 编写 `src/tools/mock_data.py`：EMPLOYEES（≥5 人，含入职日期）+ TICKETS（≥3 单，覆盖不同状态）；
- [ ] T1.3 起草 `tests/testdata.py` 测试集初稿（≥10 条，结构 `{question, gold_answer, expect_tool, domain}`），至少含：3 条制度类、1 条员工查询、1 条工单查询、**1 条知识库外问题**、1 条档位推理题。

**交付物**：6 份语料、mock_data、测试集初稿。

**验收标准**：文档可被 TextLoader 按 utf-8 读出；测试集每条 gold_answer 都能在语料中找到出处（人工核对）。

## M2 · RAG 基础管线

**任务**

- [ ] T2.1 `rag/loader.py`：load_and_split（遍历 knowledge_docs，注入 metadata，中文分隔符切分）；
- [ ] T2.2 `rag/vectorstore.py`：build_vectorstore（Chroma 持久化到 `chroma_db/`）+ load_vectorstore；
- [ ] T2.3 `scripts/ingest.py`：一键建库，打印统计（文档数/chunk 数/各域分布）；
- [ ] T2.4 `rag/retriever.py` P0 版：`as_retriever(k=3)`；
- [ ] T2.5 `rag/chain.py`：LCEL 问答链（防幻觉 Prompt + itemgetter 正确用法）；
- [ ] T2.6 `tests/test_rag_offline.py`：不调 LLM，直接验证 retriever —— 对测试集制度类问题，断言 gold 关键词出现在召回片段中（检索命中率 ≥ 80%）。

**交付物**：rag 模块 + ingest 脚本 + 离线检索测试。

**验收标准**

```bash
python scripts/ingest.py                    # 建库成功，输出 chunk 统计
python -m pytest tests/test_rag_offline.py  # 检索命中率 ≥ 0.8
# 配 Key 后手动冒烟：
python -c "from src.rag.chain import *; ..."   # 问"年假几天"得到基于语料的回答
```

## M3 · 多路召回 + Rerank（质量增强）

**任务**

- [ ] T3.1 BM25 路：`BM25Retriever.from_documents(chunks, k=20)`（需 ingest 时缓存 chunks 或重建时现切）；
- [ ] T3.2 融合：`EnsembleRetriever([向量, bm25], weights=[0.5, 0.5])`；
- [ ] T3.3 Rerank：`ContextualCompressionRetriever` + `CrossEncoderReranker(bge-reranker-base, top_n=4)`；
- [ ] T3.4 config 加开关 `RETRIEVER_MODE=basic|hybrid`，两种形态可切换对比；
- [ ] T3.5 回归：重跑 `test_rag_offline.py`，对比 P0 命中率（hybrid 应 ≥ basic，特别是含专有名词/单号类 query）。

**交付物**：完整两阶段检索链。

**验收标准**：hybrid 模式下离线检索命中率 ≥ 0.9；`04b_rag_advanced.py` 同款管线在本项目跑通。

**任务**

**验收标准**


## M6 · 测试集 + 评估 + 回归基线

**任务**

- [ ] T6.1 定稿测试集（≥12 条，覆盖 6 域 + 知识库外 + 档位推理 + 工具类）；
- [ ] T6.2 `scripts/evaluate.py`：跑全量测试集，输出三项指标：
  - context_precision（gold 关键词在召回上下文命中率）
  - faithfulness（回答被上下文支持比例）
  - tool_accuracy（工具选择正确率）
- [ ] T6.3 保存首次基线到 `tests/baseline.json`；评估脚本支持与基线对比（提升/下降）；
- [ ] T6.4 阈值门禁：faithfulness ≥ 0.8、tool_accuracy ≥ 0.9、S4 防幻觉必须通过。

**交付物**：评估脚本 + 基线报告。

**验收标准**：`python scripts/evaluate.py` 输出指标表并达标。

## 执行纪律（给实施 Agent）

1. **顺序执行**，不跳里程碑；每完成一个里程碑跑一遍该里程碑验收命令并确认输出；
2. **每个里程碑完成后**：简要记录"做了什么 / 验收结果 / 遗留问题"追加到 `docs/progress.md`（自建）；
3. **改代码前先读课程对应示例**（映射表见架构文档第 7 节）；
4. 遇到 API 用法不确定：以 `examples/` 下可运行代码为准，不凭记忆猜；
5. 卡住超过 3 次尝试：停下来，把问题与已试方案写进 progress.md 再继续；
6. 不做计划外功能（防过度工程）；发现规划与实际冲突时，以能跑通课程技术栈为准并在 progress.md 记录偏差。
